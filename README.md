# 安娜帶你看房｜實價登錄資料（自動更新）

這個資料夾是「實價登錄」的自動更新機器人，資料來源是內政部不動產成交案件實際資訊。

## 它會做什麼
- 每月 2、12、22 日自動執行（內政部每月 1、11、21 日發布最新一批）
- 下載台中市、彰化縣、南投縣的成交資料，排除特殊交易，整理成網站用的檔案
- 放在 GitHub Pages 上，官網的實價登錄頁、首頁「實價行情速報」直接讀這裡的資料

## 檔案說明
| 位置 | 內容 |
|---|---|
| `data/index.js` | 中彰投縣市與行政區目錄 |
| `data/B-01.js`… | 各行政區近兩年成交明細（B＝台中、N＝彰化、M＝南投） |
| `data/data.js` | 首頁「實價行情速報」（草屯鎮、南投市） |
| `raw/current/` | 累積的內政部最新批次原始資料（整季資料公布前用） |
| `tools/update.py` | 主程式 |
| `.github/workflows/update.yml` | 自動執行的排程 |

## 手動更新
到 GitHub 這個專案的「Actions」→「實價登錄自動更新」→「Run workflow」。

## 注意
GitHub 規定：專案 60 天完全沒有動靜，排程會被暫停。這個機器人每 10 天會自己存檔一次，正常情況下不會發生；
如果收到 GitHub 的暫停通知，到「Actions」頁面按「Enable workflow」就好。
